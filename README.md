# Парсер Кинопоиск топ-1000

Этот парсер позволяет собирать топ-1000 фильмов и информацию о них (название фильма, рейтинг, год выхода, страну производства, режиссера, возможность просмотра на кинопоиске) с сайта `kinopoisk.ru`. Собирает данные и записывает их в файл `.csv`.

## Требования

- [Python](https://www.python.org/downloads/) >= 3.10
- [Selenium](https://selenium-python.readthedocs.io/) >= 4.18.1
- [fake-useragent](https://pypi.org/project/fake-useragent/) >= 2.2.0
- [loguru](https://github.com/Delgan/loguru) >= 0.7.3

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Spisocheg/kinopoisk_parser
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd kinopoisk_parser
   ```

## Первый запуск
   
1. Создайте виртуальное окружение. В корне проекта введите следующее:
   ```bash
   ... > python -m venv venv
   ```
2. После некоторой загрузки в корне проекта появится новая папка (с именем `venv`). Активируйте виртуальное окружение:
   ```bash
   ... > .\venv\Scripts\activate
   ```
3. В начале строки добавится имя виртуального окружения в скобках. Установите требуемые для работы библиотеки:
   ```bash
   (venv) ... > python -m pip install -r .\requirements.txt
   ```
4. После установки пакетов можете перейти к запуску:
   ```bash
   (venv) ... > python main.py
   ```
   *консоль не должна ничего выводить

## Использование

### Запуск
1. Перейдите в папку с проектом. Активируйте виртуальное окружение:
   ```bash
   ... > .\venv\Scripts\activate
   ```
2. В начале строки добавится имя виртуального окружения в скобках. Запустите скрипт:
   ```bash
   (venv) ... > python main.py
   ```

### Результат
После обработки всех страниц в папке с проектом появится файл `result_YYYY-MM-DD.csv`, где `YYYY-MM-DD` - дата парсинга в формате `ГГГГ-ММ-ДД` (например, `2025-04-30`). Содержимое файла будет представлять собой таблицу с колонками: `Название фильма`, `Рейтинг`, `Страна`, `Год`, `Режиссёр`, `Наличие на Кинопоиск` (последняя представляет собой значения `True` или `False`, соответственно означающие возможность просмотра на Кинопоиске по подписке Плюс или невозможность оного). Данные разделены точкой с запятой (`;`).
